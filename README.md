# Git and GitHub Version Control Lab

A practice repository for learning Git commands, branching, merging, and version control workflows.

## Project Structure

- `hello.txt` — Initial greeting file
- `app.py` — Simple Python application
- `.gitignore` — Git ignore rules

## Commands Practiced

- `git init` — Initialize repository
- `git add` — Stage changes
- `git commit` — Save snapshots
- `git branch` — Manage branches
- `git merge` — Merge branches
- `git log` — View history
- `git diff` — View changes
- `git stash` — Temporary storage
